# Recommendation Systems Benchmark

Сравнительный анализ классических и нейронных рекомендательных алгоритмов в сфере электронной коммерции.

## О проекте

Исследование посвящено вопросу: насколько эффективность рекомендательных моделей зависит от того, к какому сегменту принадлежит пользователь? Пользователи сегментированы методом k-means на основе поведенческих признаков (RFM и его расширение). Для каждого сегмента обучены и сопоставлены модели разных классов.

## Реализованные модели

- Most Popular (baseline)
- Гибридная модель на основе логистической регрессии
- Item-based коллаборативная фильтрация (KNN)
- Матричная факторизация с BPR-оптимизацией (MF-BPR)
- Neural Collaborative Filtering (NCF)
- LightGCN

## Технологии

Python, PyTorch, scikit-learn, pandas, numpy, scipy
